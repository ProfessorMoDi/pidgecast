# Pidgecast (Next.js app)

The interactive dashboard lives in this folder. **Full documentation** — architecture, analysis pipeline, deploy — is in the [repository README](../README.md).

## Quick start

From the **repo root**:

```bash
npm install
npm run dev
```

Or from this directory:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy (Vercel)

Set **Root Directory** to `pidgecast` when importing the repo.
